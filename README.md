# 🛍️ OpenCart E-commerce Platform
## 📌 Overview

**OpenCart** is a free and open-source e-commerce platform designed to empower online merchants with a professional and flexible solution for building online stores. Whether you're a seasoned developer or a first-time business owner, OpenCart's intuitive design and robust feature set provide everything you need to run a successful e-commerce site.

## 📌 Project Summary

This project focuses on evaluating and improving the functionality of the **OpenCart e-commerce platform**. Key areas include front-end usability, cart operations, checkout processes, and account management.

## 👨‍💻 Responsibilities

- Created detailed **Functional Requirements Document** for OpenCart's default store features.
- Designed and executed **Test Cases** to validate key user journeys (navigation, cart, checkout, account creation).
- Reported and documented bugs with **clear descriptions**, **reproduction steps**, and **severity levels**.
- Focused on enhancing **user experience**, **payment flow**, and **shopping cart performance**.
- Collaborated with developers and testers to resolve issues and improve **product stability**.

## 🚀 Features

- ✅ Easy-to-use storefront interface
- 🎨 Customizable themes and layouts
- 📦 Product management with categories, images, and pricing
- 💳 Multiple checkout options: Guest, Registered, and One-Page Checkout
- 🌐 Multi-currency and multilingual support
- 📈 Order management and analytics
- 🛠️ Extension support and third-party integrations
  
## 🧰 System Requirements

To install and run OpenCart successfully, ensure your hosting environment includes:

- **PHP**: 5.4 or above
- **MySQL**: Recommended database
- **Web Server**: Apache preferred
- **Client-Side Libraries**:  
  - jQuery 2.1.1  
  - JavaScript enabled

## 👤 Customer Account & Checkout Flow

### 🔐 Account Creation
- Guest checkout or register
- Login via "My Account"

### 🧾 6-Step Checkout Process
1. **Checkout Options**: Guest or Registered
2. **Billing Details**: Name, Email, Address
3. **Delivery Details**: Optional (can match billing)
4. **Delivery Method**: Shipping options + comments
5. **Payment Method**: Payment options + comments
6. **Confirm Order**: Summary before placing the order
